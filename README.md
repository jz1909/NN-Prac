# Makemore with all credit to the methods of [Bengio et al. 2003](https://www.jmlr.org/papers/volume3/bengio03a/bengio03a.pdf) and Andrej Karpathy

This version of makemore is a small neural network that intakes a text file and generates more output that follows the same pattern. The example here takes a text file with a list of names and trains the model to output more names based on what it's learned. 
Refactored in a .py from previous .ipynb iterations
